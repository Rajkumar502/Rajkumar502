### About me

I bring one discipline to every system I build: find the actual problem, understand what it costs the business, and resolve it in a way that holds up under real use.

That discipline was shaped over **14 years in test automation and quality engineering**, and it now drives how I design **agentic AI systems** and **retrieval-based (RAG) pipelines** — from task orchestration and multi-agent workflows to grounding responses in verified data rather than assumption.

My focus is practical: whether an AI system is reliable enough to run without supervision, and whether it saves the business meaningful time or cost.

### Featured projects

**Agentic Workflow Automation**
Autonomous SDLC framework (Playwright, TypeScript, LLM, MCP) that reads Jira requirements, generates test code, self-heals on failure, and separates real defects from flaky environments.

**Multi-Agent Orchestration**
4-agent tutoring system (LangGraph) with memory scoring — optimized to cut token usage by 95%+ and latency by more than 2x.

**Agentic Support Automation**
Multi-agent support workflow (LangGraph, RAG, FastAPI, Docker) with intent classification, confidence gating, and production-pattern security guardrails including PII masking and prompt-injection defense.

**Applied RAG and Knowledge Grounding**
Open-source RAG assistant (LangChain, ChromaDB, Ollama) with strict source citation and deterministic refusal on undocumented queries.

**Multimodal AI**
Multimodal assistant (CLIP, FAISS, Florence-2) for auto-captioning, natural language visual search, and visual question answering across an image catalog.
